# [ vpsscan ]

**Simple VPS security scanner for Linux.**

A lightweight tool to quickly audit a Linux server for common security misconfigurations and open ports.

### ➔ Installation
\`\`\`bash
curl -L sh.serghini.me/vpsscan -o vpsscan.sh
chmod +x vpsscan.sh
./vpsscan.sh
\`\`\`
